# GNN 社交图谱链接预测 — 阶段性报告

> 2026-05-29 | CAAI-BDSC2023 竞赛项目

---

## 一、项目概述

**任务**：给定 (inviter, item, timestamp)，预测会分享给哪个 voter。

**数据**：~720K 分享记录，111,770 用户，438,164 商品，train_lgb 2.4M 行 (1:3 正负比)。

**方法栈**：LightGBM (表格特征) + GNN/DySAT (图结构) 双路线。模块化框架 `modules/` 支持交叉组合实验。

## 三、做了什么 (按时间线)

### Phase 1: 模块化框架搭建

```
modules/
├── feature_selector.py   # 4种特征选择器 (Identity/SHAP/PCA/SHAP+PCA)
├── models/
│   ├── lgb_model.py      # LightGBM 标准接口
│   ├── gnn_model.py      # GraphSAGE/GCN/GAT + LinkPredictor
│   └── dysat_model.py    # 多快照 + TemporalAttention
└── experiment.py         # Config驱动交叉组合, 自动AB对比
```

标准接口：`fit() → predict_proba() → evaluate() → evaluate_mrr()`，无缝切换模型。

### Phase 2: GNN + Item 特征 (今天)

**改动**：LinkPredictor 增加 ItemEncoder — cate_id/brand_id/shop_id Embedding + cate_virality 数值 → 32维 → 注入预测。

**效果**：GNN MRR 从 0.21 → 0.33 (+53%)，DySAT 从 0.22 → 0.31 (+40%)。

**但**：诊断发现 ItemEncoder 对所有候选人输出相同 embedding，item 信息实际上对**候选人排序**的贡献为零。MRR 的提升主要来自 item 作为全局 context 对 inviter 行为的调制。

### Phase 3: 深度诊断 (今天)

#### 诊断1: 数据切分

结论：**不是瓶颈**。92.1% 的验证正样本双方都在 GNN 图中。

#### 诊断2: SHAP/PCA 优化目标

结论：**SHAP 和 PCA 都围绕 AUC 优化，与 MRR 无关。**
- SHAP top-K = 对 AUC 分类贡献最大的 K 个特征
- PCA 保留方差 ≠ 保留排序信号
- 边特征(is_friend等) SHAP 排名 110-115/119，但对 MRR 场景1 是决定性特征

#### 诊断3: Item 特征在 MRR 中的实际作用

结论：**趋近于零。**
- cate_id SHAP rank 105/119
- brand_id SHAP rank 107/119
- shop_id SHAP rank 108/119
- cate_virality_score SHAP rank 109/119

#### 诊断4: DySAT 时序信号

结论：**基本无用。**
- 快照间仅新增 7% 边，71% 用户度不变
- 时间跨度仅 38 天
- 加了 item 特征后 DySAT 反而退步 (-5%)

#### 诊断5: 跨模型特征覆盖

结论：**LGB 和 GNN 操作在两套完全不同的特征空间。**

```
LGB 独有 (GNN没有):          GNN 独有 (LGB没有):
├── 边特征 (is_friend等)     ├── 图结构消息传递
├── 图拓扑 (CN/Jaccard等)    ├── 64维节点embedding
├── 样本级用户对比 (96维)     └── 隐式社区发现
└── 用户-品类深度交叉 (38维)

共同拥有:
├── 用户画像 (52维 vs 96维展开)
└── 物品信息 (5维 vs 4→32维)
```

#### 诊断6: 缺失特征

结论：**per-(voter, item) 交互特征完全缺失。** 这是 MRR 上不去的**主因**。

当前没有任何特征回答："对于这个具体的商品，这个候选人 voter 有多大概率会接收？"

验证实验：单特征规则 (voter 是否接收过该 item 的品类) 就能达到 MRR=0.18——超过 GNN 无 item 版 (0.21) 的 85%。

## 四、核心发现总结

| # | 发现 | 影响 |
|---|------|------|
| 1 | LGB 是最稳定的基线，AUC 0.90 / MRR 0.56 | 短期内难以超越 |
| 2 | GNN AUC 极高 (0.98) 但 MRR 低 (0.33) — AUC ≠ MRR | 图结构擅长分类，不擅长排序 |
| 3 | GNN 在场景2 (冷启动) 碾压 LGB (0.54 vs 0.09) | 图嵌入有独特价值，但被场景1拖累 |
| 4 | BCE loss + 共享 item_emb = GNN 无法学习排序 | 架构层面需要改动才能做 MRR |
| 5 | DySAT 时序信号极弱，基本是负优化 | 数据不支持动态建模 |
| 6 | 119 维特征缺少 per-(voter,item) 交互特征 | **MRR 最大的可提升空间** |
| 7 | SHAP/PCA 优化 AUC，对 MRR 无直接帮助 | 需要 ranking-aware 的特征选择方法 |

## 五、下一步方向

### 短期 (确定性高)

> **构造 per-(voter, item) 匹配特征 → 加入 LGB → LambdaRank 训练**
> 预期：MRR 从 0.56 → 0.60~0.65

### 中期 (值得探索)

> **GNN 64维 embedding → 注入 LGB 作为额外特征**
> 预期：利用 GNN 在场景2的优势 (0.54) 补 LGB 的短板 (0.09)

### 长期 (边际递减)

> **MRR-GNN (BPR loss + hard negative + per-candidate item feat) + 三模型 Ensemble**
> 预期：MRR → 0.65~0.70，但工程复杂度显著增加
