# 用户画像维度体系 — 北极星指标驱动设计

## 北极星指标：精准分享回流率

> 定义：分享后实际产生回流的人数 / 分享触达的总人数
> 公式：P( voter 回流 | inviter 分享商品 X )

---

## 指标拆解（OSM 框架）

```
O (目标)   — 分享回流率 ↑
S (策略)   — 分享专栏推荐 + 激励机制
M (指标)   — 见下方层级指标体系

分享回流率 = f(
    inviter(分享者特征),   ← 用户画像覆盖
    voter(接收者特征),     ← 用户画像覆盖
    item(商品特征),        ← 商品侧特征覆盖
    edge(关系特征)         ← 朋友圈边级特征覆盖
)
```

---

## 用户画像层级指标体系（5 层 × 52 维特征）

### Layer 1: 用户价值层 (Value) — 这个人在回流这件事上"值多少"

| 特征 | 含义 | 与北极星的关系 |
|------|------|-------------|
| share_out_count | 历史分享次数 | 分享越多, 产生回流的基数越大 |
| share_out_unique_voter | 分享给了多少不同的人 | 受众广度 |
| share_out_unique_item | 分享过多少不同商品 | 内容产出力 |
| share_in_count | 被分享的次数(作为voter) | 回流频率(接收侧) |
| share_in_unique_inviter | 被多少人分享过 | 社交吸引力 |
| share_success_rate | 分享→回流的转化率 | **北极星的直接代理指标** |
| role_score | 分享者 vs 消费者倾向(0~1) | 角色定位 |
| pagerank | 图中心性 | 社交网络影响力 |
| in_degree_graph | 多少人向我分享过 | 入边数量 |
| out_degree_graph | 我分享给了多少人 | 出边数量 |
| total_degree_graph | 总连接数 | 网络规模 |
| is_active_sharer | 是否活跃分享者(布尔) | 快速筛选 |
| is_active_target | 是否活跃被分享者(布尔) | 快速筛选 |

---

### Layer 2: 行为模式层 (Behavior) — 这个人怎么用平台

| 特征 | 含义 | 与北极星的关系 |
|------|------|-------------|
| share_out_first_time | 第一次分享时间 | 用户生命周期起点 |
| share_out_last_time | 最近一次分享时间 | 活跃度新鲜度 |
| share_out_active_days | 有多少天在分享 | 活跃持续性 |
| share_out_avg_per_day | 日均分享次数 | 活跃强度 |
| share_in_first_time | 第一次被分享时间 | 作为接收者的起点 |
| share_in_last_time | 最近一次被分享时间 | 接收活跃度新鲜度 |
| share_in_active_days | 有多少天在被分享 | 接收持续性 |
| share_in_avg_per_day | 日均被分享次数 | 接收频率 |
| days_since_last_share | 距最近分享几天(Recency) | **流失预警** |
| days_since_last_receive | 距最近被分享几天 | 被遗忘预警 |
| days_since_last_activity | 距最近任何活动几天 | 综合活跃度 |
| activity_trend | 活跃度在上升(>0)还是下降(<0) | **趋势信号**: 在走上坡还是下坡 |
| weekend_ratio | 周末活动占比 | 周末型/工作日型用户 |
| night_ratio | 夜间活动占比(22~5点) | 夜猫子型用户 |
| burstiness_out | 分享爆发度(-1~1, >0=集中爆发) | 稳定型 vs 爆发型 |
| burstiness_in | 被分享爆发度 | 被动行为稳定性 |

---

### Layer 3: 内容偏好层 (Content) — 这个人喜欢什么

| 特征 | 含义 | 与北极星的关系 |
|------|------|-------------|
| pref_cate_inviter | 作为分享者最常分享的品类 | 个人口味 |
| pref_cate_inviter_count | 首选品类分享次数 | 偏好强度 |
| pref_cate_voter | 作为回流者最常回流的品类 | 被什么内容吸引 |
| pref_cate_voter_count | 首选品类回流次数 | 回流偏好强度 |
| cate_entropy_out | 品类熵(0=专注, 高=广泛) | 兴趣广度 vs 深度 |
| cate_diversity_out | 分享覆盖的品类数 | 内容多样性 |
| top_cate_ratio_out | 最常用品类占比 | 品类集中度 |
| brand_entropy_out | 品牌熵 | 品牌忠诚度 |
| brand_diversity_out | 分享覆盖的品牌数 | 品牌多样性 |
| top_brand_ratio_out | 最常用品牌占比 | 品牌集中度 |
| item_diversity_out | 商品多样性(unique_items/count) | 内容重复度 |
| item_diversity_in | 接收商品多样性 | 接收内容的广度 |
| share_in_unique_item | 被分享的不同商品数 | 作为回流者接触的内容广度 |

---

### Layer 4: 社交关系层 (Social) — 这个人在社交网里的位置

| 特征 | 含义 | 与北极星的关系 |
|------|------|-------------|
| out_repeat_ratio | 重复分享给同一个人比率 | 固定搭子 vs 广撒网 |
| in_repeat_ratio | 被同一个人重复分享的比率 | 固定来源 |
| avg_out_per_voter | 平均每人分享多少次 | 关系深度(出) |
| avg_in_per_inviter | 平均每人被分享多少次 | 关系深度(入) |
| network_growth_rate | 新联系人增长率 | 社交圈在扩张(>1)还是收缩(<1) |
| response_latency_days | 从被分享到主动分享的间隔 | 响应速度: 主动型(<0) vs 被动型(>0) |
| share_ratio | 分享/被分享比值 | 社交角色平衡度: >1偏分享者, <1偏接收者 |

---

### Layer 5: 基础属性层 (Identity) — 这个人是谁

| 特征 | 含义 | 与北极星的关系 |
|------|------|-------------|
| gender | 性别(0/1/-1=未知) | 人群细分 |
| age | 年龄段(1~8, -1=未知) | 年龄段细分 |
| level | 平台积分等级(1~10) | 平台经验/投入度 |

## 设计方法论：为什么不用聚类

```
传统做法 (CDA 教的标准流程):
  RFM 量化 → K-means/GMM 聚类 → 分群标签

我们的做法:
  业务假设 → 规则化分层 → 特征矩阵 → SHAP 后验验证 → 修正假设
                                          ↑
                              这里才是"客观论证"环节
                              聚类做不到这一步
```

**核心论据**：
1. K-means 不可解释 — "第3类用户"没有业务含义
2. 链接预测是双边问题 — 答案在边上(A-B关系), 不在节点上(A是谁)
3. SHAP 是画像设计的终点裁判 — 不是凭经验砍维度, 拿证据砍

## 面试话术（完整版）

> "画像维度设计采用了五层指标体系, 围绕北极星指标'分享回流率'逐层拆解:
>
> 五层分布：用户价值 13 维 + 行为模式 16 维 + 内容偏好 13 维 + 社交关系 7 维 + 基础属性 3 维 = 52 维。
>
> 用户价值层回答'这个人在回流这件事上价值多大',
> 行为模式层回答'他什么时候会行动',
> 内容偏好层回答'什么内容能吸引他',
> 社交关系层回答'他在社交网里扮演什么角色',
> 基础属性层做人群细分。
>
> 52 维特征是假设, SHAP 特征重要性是验证。
> SHAP 告诉我不只是'哪个维度重要', 而是'活跃度比品类偏好重要 3 倍'这种定量结论 —
> 这直接指导了后续 GNN 的降维方向和 A/B 测试的实验分组策略。"
